# Челбаскет ТВ

Репозиторий содержит Windows-приложение и исходники плагина «Челбаскет ТВ-обложки».

## Windows-приложение

Выбери турнир и дату — приложение найдёт игры на сайте Федерации баскетбола Челябинской области, скачает новые ТВ-обложки и подготовит:

- `games.txt` со списком игр и датой `dd.mm.yyyy`;
- `game_ids.txt` с порядковыми номерами и ID матчей;
- `post.txt` с гиперссылками на обе команды, если указана первая ссылка трансляции;
- PNG-расписание на день с названием турнира и категорией;
- папку со скачанными обложками, расписанием и ZIP-архив с полным пакетом.

Пост можно скопировать из предпросмотра. Программа не создаёт трансляции и не публикует записи во ВКонтакте.

## Скачать и запустить приложение

1. Открой [сборки Windows-приложения в GitHub Actions](https://github.com/shieFak/CRBF_post/actions/workflows/windows-app.yml).
2. Выбери самый свежий успешный запуск **Windows app** с зелёной галочкой. Если сборка ещё выполняется, дождись её завершения.
3. Внизу страницы запуска найди **Artifacts** и скачай `ChelbasketDesktop-win-x64`.
4. Распакуй скачанный ZIP в удобное место.
5. Открой папку и запусти `ChelbasketDesktop.exe`. Если Windows покажет предупреждение о скачанном файле, проверь, что файл получен из этого репозитория, и выбери **«Всё равно запустить»**.

При запуске программа сама загружает актуальный список турниров с сайта Федерации. Выбери турнир и дату, нажми **«Найти игры»**, проверь пост и при необходимости добавь первую ссылку на трансляцию. Затем выбери папку результата и нажми **«Скачать обложки и собрать пакет»**. В указанной папке появится набор файлов и ZIP-архив. Пост можно скопировать из вкладки **«Пост»**.

При появлении новой версии программа предложит открыть страницу релиза. Скачай новый `ChelbasketDesktop.exe`, закрой приложение и замени им прежний файл.

Для работы нужен Microsoft Edge WebView2 Runtime — он обычно уже установлен в Windows 10/11. Если приложение сообщает, что WebView2 не найден, установи Evergreen Runtime с [официальной страницы Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/).

Артефакт сборки хранится в GitHub Actions 90 дней. После этого скачай артефакт из более свежего успешного запуска.

Для рендеринга картинок нужен Microsoft Edge WebView2 Runtime. На большинстве компьютеров Windows 10/11 он уже есть. Если его нет, установи Evergreen Runtime с [официального сайта Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/).

## Плагин

Плагин выполняет тот же рабочий сценарий в совместимой среде ассистента: находит матчи, скачивает обложки в новом дизайне, составляет список игр и генерирует `post.txt`. Он не является автономной программой и не загружает публикации во ВКонтакте.

## Структура репозитория

- `plugin.json` и `skills/download-tv-covers/SKILL.md` — файлы плагина.
- `windows-app/ChelbasketDesktop/` — исходники Windows-приложения.
- `windows-app/publish.ps1` — сборка portable EXE локально.
- `.github/workflows/windows-app.yml` — автоматическая сборка EXE на GitHub Actions.
