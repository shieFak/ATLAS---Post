# Windows-приложение

`Атлас` — portable WPF-приложение для Windows x64. Оно повторяет рабочий процесс плагина «Челбаскет ТВ-обложки»:

1. Загружает список турниров с сайта Федерации баскетбола Челябинской области.
2. Находит игры выбранной даты, включая прошедшие и предстоящие матчи.
3. Скачивает PNG-обложки через штатную кнопку экспорта на странице нового дизайна.
4. Формирует и скачивает PNG-расписание на выбранную дату с названием турнира и категорией.
5. Создаёт `games.txt`, `game_ids.txt`, `post.txt` и ZIP рядом с папкой пакета. В архив входят обложки и расписание.

Ссылки на трансляции указываются необязательно. Если передана первая ссылка формата `https://vkvideo.ru/live-123456789_456239001`, приложение прибавляет `1` к последнему ID для каждой следующей игры. Без ссылки в посте остаётся шаблон `[|Команда 1 - Команда 2]`.

Пост можно скопировать из предпросмотра. Приложение не создаёт трансляции и не публикует посты во ВКонтакте.

## Скачать готовый EXE

После отправки изменений в ветку `main` GitHub Actions собирает `Atlas.exe`. Открой раздел **Actions**, выбери последний успешный запуск `Windows app`, затем скачай артефакт `Atlas-win-x64`.

Приложению нужен Microsoft Edge WebView2 Runtime для отображения и экспорта обложек. Он уже установлен на большинстве Windows 10/11 компьютеров. Если его нет, установи Evergreen Runtime с [официальной страницы Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/).

## Выпустить обновление

Версия приложения хранится в `<Version>` в `ChelbasketDesktop.csproj`. После изменения исходников увеличь её, например до `1.0.1`, отправь коммит в `main`, затем создай и отправь тег:

```powershell
git tag app-v1.0.1
git push origin app-v1.0.1
```

GitHub Actions соберёт EXE и опубликует релиз. Приложения с более ранней версией при запуске сообщат об обновлении и предложат открыть страницу релиза. Пользователь скачивает новый EXE и заменяет прежний после закрытия приложения.

Нужен .NET 10 SDK для Windows:

```powershell
.\windows-app\publish.ps1
```

Portable-файл появится в `windows-app/publish/Atlas.exe`. Для работы ему нужен WebView2 Runtime; сам .NET включён в EXE.

## Структура

- `ChelbasketDesktop/` — исходники WPF-приложения.
- `publish.ps1` — локальная публикация single-file EXE.
- `../.github/workflows/windows-app.yml` — автоматическая сборка артефакта для GitHub.
